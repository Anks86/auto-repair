Our goal

This website aims to meet Web Content Accessibility Guidelines 2.1 Level AA. Accessibility is reviewed as the content and technology change.

What the website does

  • Uses clear headings, plain language, real labels, and predictable navigation.
  • Supports keyboard navigation, visible focus, and a skip link.
  • Uses text alternatives for meaningful images and hides decorative images from assistive technology.
  • Keeps Call and Text actions easy to reach, including on phone-width screens.
  • Uses strong colour contrast and does not rely on colour alone to communicate meaning.
  • Stops automatic movement when reduced motion or browser data-saving mode is requested.
  • Provides manual controls for every carousel.
  • Uses labelled form fields, clear validation, and status messages that assistive technology can announce.

Known limitations

Google review pages, Cloudflare Turnstile, phone dialers, and messaging applications are third-party experiences. Their accessibility can vary by device and service provider.

If the website form presents a barrier, customers can call, text, or email Babbal directly.

Accessibility feedback

Tell Babbal what page or task caused difficulty, what device or assistive technology you were using if you are comfortable sharing it, and how you would like a reply.
